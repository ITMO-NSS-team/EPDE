Tokens written as formulas (robot i at time t):
  cos φ_i, sin φ_i     heading of the robot's marker
  x_i, y_i             centre position relative to the arena centre (lone robot: to its track mean);
                       r_i = (x_i, y_i), ρ_i = |r_i|, R = arena radius of robot centres
  r_ij = |r_i − r_j|   centre distance to robot j;  σ = 230 px, the robot diameter (≈ 5 cm)
  H(z)                 step: 1 for z > 0, else 0
  τ = 0.4 s (10 frames), w = 0.08 s (2 frames); ω_i = the robot's own mean spin rate
  f_i                  the drift law's prediction of (r_i(t+τ)−r_i(t))/τ (noise law only)
Token -> formula:
  c, s                 cos φ_i, sin φ_i
  push_x, push_y       Σ_{j: r_ij<1.1σ} (x_i−x_j)/r_ij,  Σ_{j: r_ij<1.1σ} (y_i−y_j)/r_ij
  wall_x, wall_y       H(ρ_i−R+σ/4)·(−x_i/ρ_i),  H(ρ_i−R+σ/4)·(−y_i/ρ_i)
  vb_x, vb_y           (x_i(t)−x_i(t−τ))/τ,  (y_i(t)−y_i(t−τ))/τ
  x, y                 x_i, y_i
  dc/dx0, ds/dx0       d(cos φ_i)/dt, d(sin φ_i)/dt   (central derivatives)
  dx/dx0, dy/dx0       robot systems: (x_i(t+τ)−x_i(t))/τ,  (y_i(t+τ)−y_i(t))/τ   (forward increments)
                       velocity level: (x_i(t+w)−x_i(t))/w,  (y_i(t+w)−y_i(t))/w
  d^2x/dx0^2           (x_i(t+2w)−2x_i(t+w)+x_i(t))/w²   (and the same in y)
  n_contact            Σ_j H(1.1σ−r_ij)   (number of touching neighbours)
  wall, r/R            H(ρ_i−R+σ/4),  ρ_i/R
  |vb|, |w|            |r_i(t)−r_i(t−τ)|/τ,  |ω_i|
  D                    (τ/4)·|(r_i(t+τ)−r_i(t))/τ − f_i|²   (diffusion, px^2/s)
Units: positions px, velocities px/s, rates rad/s. Coefficients are EPDE's, unchanged.

Every law per data file, printed the way EPDE prints a system (search.equations()).

Per robot i of a recording (each robot its own system, its own spin and propulsion tokens):
    dc/dx0 = -w_i s,   ds/dx0 = w_i c                                 (central derivatives)
    dx/dx0 = a_i c - b_i s + mu_P push_x + mu_W wall_x + a vb_x + c_x   (forward increment, 0.4 s)
    dy/dx0 = b_i c + a_i s + mu_P push_y + mu_W wall_y + a vb_y + c_y
a_i + i b_i = v0_i e^{i theta_i} is the robot's OWN propulsion (speed v0_i, direction theta_i from the
marker heading); mu_P, mu_W, a, c_x, c_y are shared by the robots of the recording (joint least squares).
Held out (first half -> second half) this per-robot propulsion raises R2 0.17-0.27 -> 0.31-0.63; per-robot
push / wall / persistence / constants add < 0.03 (scratchpad per_robot_ablation.py).
Velocity level (0.08 s windows, d^2x/dx0^2 = dv_x/dt) and the noise law (D = squared increment / 2 dt)
are per recording, read from results/wide_friction.json and results/diffusion.json (exact
(WAPE, win14) fronts, stable end = least window-unstable member).
Objective function values: [WAPE of every equation ..., window instability win14 of every equation ...].
