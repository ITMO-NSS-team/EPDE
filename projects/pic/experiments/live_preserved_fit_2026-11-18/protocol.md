# Live search with held-out weak windows

Run three paired 5% noise recordings (seeds 916201–916203) for ode_simple, Van der Pol, wave, Allen–Cahn and nonlinear diffusion (pde_compound). The nonlinear diffusion case had the largest full-record TLS gain on the fixed panel. The other four span the previous live search cases. Ten NSGA-II epochs per arm and the native automatic population give a 45-search screen. Match observations, seeds, token library, search budget, fourth-order FD, native WLS support and printed coefficients, amplification and degeneracy guards, and directional dyad. The search uses plain mode and the full nondominated front.

The three first objectives are native WAPE, blocked WLS residual energy, and blocked unit-column TLS residual energy. Each blocked arm uses the native, per-record weak plan. Select a feasible split axis by maximizing the smallest number of centers across dimensions on the shorter half, then total centers, then axis order. Rebuild weak columns from raw data separately inside the two halves at the original grid spacing, with the original window and stride. Retain native one-sided edge handling and explicit constants. The native plan and data-derived trig frequencies see the whole recording. The internal holdout tests the coefficient fit conditional on those design choices.

Train on one half, evaluate the other, reverse and average. Divide each mean squared validation residual by the sum of squared training-RMS-weighted coefficients. Invalid or nonunique fold fits use the native failed-objective marker. TLS uses a homogeneous vector, WLS uses the evolved target. Each arm keeps the native full-data WLS fit for reporting. Save an additional full-data TLS refit of front supports as a coefficient diagnostic.

Count exact registered supports and accepted identities on the final front, including constants. Record the nearest term-set distance and whether a registered law reached the objective evaluator before selection. Use benchmark truth only for bookkeeping. Verify the actual first objective on every front member; preserve the realized target and dyad for joint comparisons. These five scalar systems and short budgets are a screen for transfer beyond a hand-assembled panel.
