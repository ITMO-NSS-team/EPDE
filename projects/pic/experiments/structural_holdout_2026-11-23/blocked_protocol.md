# Four-fold cross-validation of discovery on raw slabs

For each dataset partition the longest grid axis into four contiguous equal-sized slabs, dropping at most three trailing samples. Rotate the withheld slab through all four locations. Give the other three slabs to native EPDE as separate training trajectories at their original coordinates. Derivatives, weak windows and spectra are computed inside each raw slab. The common weak geometry is chosen from the first available training slab. The token estimator sees all three training trajectories. A fold learns its structure, actual frequencies and coefficients before scoring any observation in the withheld slab.

Use all 15 default systems plus the separate harmonic oscillator control, and the three screening seeds. Four searches of 750 native objective fits total 3,000 per dataset and seed. Use native search without the candidate-conditioned frequency refinement. Compare with native single-block discovery at 750 and 3,000 fits and its original disjoint validation block. Report fold-level recovery and a single list of six for each record separately. Four folds on one field are dependent observations.

For each fold, record the actual candidate systems present in the search archive. Pick the representative of a given structure using only training residual and training dyad ranks, then evaluate that representative with its original coefficients on the excluded slab. Match coupled slots in their stored order. Match term supports without regard to pivot, preserving factor powers and coordinate axes. Frequencies from separate folds count as the same family only within 1% of a fixed observed anchor. No catalog labels enter grouping. Rank families by the number of folds returning a finite eligible held-out representative, then by mean held-out residual/stability percentile rank and a deterministic tie break. Return the actual representative with the lowest training percentile rank among the qualifying folds. Report recovery with registered alternatives and the top-one outcome. Also report each independent fold's six-candidate held-out list. The withheld scores used to select the consensus are internal validation scores. Catalog structure recovery is the external outcome.

The native fill-and-prune mutation falls back to the originally drawn mutation when there is more than one training trajectory. Add a contiguous native control with this identical fallback at 3,000 evaluations and at the 750-evaluation prefix, so the split comparison can be read both with and without this implementation difference.
