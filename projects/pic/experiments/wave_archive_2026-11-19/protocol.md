# Candidate retention under independent wave-profile validation

Run six fresh plain-mode native WAPE–dyad wave searches with seeds 919101 through 919106, ten NSGA-II epochs, and the previous 5% noise and weak-window settings. Record the actual native coefficients and parameters of all scored equations. Retain explicit intercepts and target orientations. Compare the returned source front, the whole terminal population, and the complete scored archive. Apply the same source eligibility rules to all three sets. Reference labels are used only after scoring for the recovery count. A candidate must have been generated by the live search.

The primary held-out field is an independently constructed analytic standing wave with spatial modes 1, 3 and 4, nonzero initial velocity, and speed 0.2. Match its mean and standard deviation to the original clean benchmark. This field shares no observations with the fitted trajectory. We found duplicate files for the standard 1D benchmark rather than a separately observed raw trajectory. Repeat at speeds 0.22 and 0.4 using the same initial displacement, component coefficients, offset and amplitude, with initial velocity held fixed across speeds. The speed-0.22 test measures the response to a modest misspecification. On single-speed controls the same symbolic support remains valid with a different coefficient. The benchmark coefficient is frozen before validation.

Also use the original field with fresh noise, and the earlier benchmark plus mode 3 and plus mode 4 at speed 0.2, as continuity checks. Eight paired independent 5% noise realizations per field and seed. Compare the WAPE–source-dyad Pareto fronts with and without the existing blocked-WLS cutoff of one. Compute block fits only on the discovery trajectory. Report recovery, number of distinct surviving supports and targets, representative competitors, and how frequently the fixed law passes the block check on the speed controls. Give separate counts for the two-derivative support without an intercept and for forms with extra terms.
