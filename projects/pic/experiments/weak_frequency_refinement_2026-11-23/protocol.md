# Training-only frequency refinement

Compare the native two-peak-per-axis library with a library of the same size in which a peak may move before search. Use the native search, weak windows, train/held split, seeds 923301–923303, 3,000 discovery evaluations, 15-system suite and separate oscillator control from the preceding experiments. Recovery requires a complete registered system in an actual candidate on the held-out nondominated front. A positive paired balance at 3,000 total fits advances the frozen rule to seeds 923601–923612.

For calibration, form first- and second-time-derivative targets of each observed variable on the training weak windows. For each target, select up to three background columns by residual gain. The background bank contains the intercept, field powers up to the search setting, pairwise field products, first and second coordinate powers, configured pure spatial derivatives and, for a second-order target, first time derivatives. At each native spectral peak screen sine and cosine alone and multiplied by a measured field or its first time derivative. Exclude a modulator equal to the target. Select the target and one modulated harmonic that explain the largest fraction of its remaining squared residual at the original peak. The candidate equation used for calibration is a training diagnostic. EPDE searches the ordinary configured term library after the grid is frozen.

Profile that harmonic's continuous angular frequency by weak least squares, refitting its linear coefficients at each trial. Stay within half a Fourier bin of the initial peak, the positive Nyquist band and the midpoints to adjacent peaks. Keep the initial point and test both interval endpoints as well as the bounded optimizer's result. Accept a move only if its training residual reduction pays a one-parameter BIC penalty and squared residuals also decrease in both training half-blocks along that axis. These checks use frozen calibration coefficients on windows lying entirely within each half. Each half must have more rows than fitted coefficients. Failing any check preserves the original peak exactly.

Charge each fitted background support and each distinct profiled-frequency fit as an additional objective-fit equivalent. Count the initial vectorized gain screening separately as projections. A cached frequency evaluation incurs zero additional fits. No benchmark labels, held-out fields or search outcomes select frequencies. Record both grids, the selected calibration support, residuals, acceptance decision, elapsed time and both budget clocks. Reuse the verified native archives for the screen. Check data hashes, requested settings, window geometry, initial peaks and native replay scores in each pair.
