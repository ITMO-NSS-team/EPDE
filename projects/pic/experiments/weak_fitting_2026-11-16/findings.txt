Implemented and tested solver-free weak fitting: core 15, 2026-11-16

The adaptive weak fitting step repairs major coefficient errors on KS, KdV,
nonlinear diffusion and pde_divide, but is not a universal replacement. The
main raw-CLSM variant retains a catalog-valid equation in 49/60 equation-seed
cases, versus 50/60 for the previous fit with the SAME residual cross-product
and dyad objectives. KS improves from 0/3 to 2/3; AC loses one case and the two
NS momentum slots lose one each. The ODE structural results are unchanged.

What was implemented:
- Train-only adaptive windows using the existing PCR criterion: weak feature
  noise amplification plus sensitivity to doubling the grid spacing.
- Raw weak regression with integration by parts, mean correction and signed
  corrected least-squares moments; nested bootstrap counts assess sensitivity.
- A matched reconstructed-field fitting arm on the identical selected windows
  to separate the window change from removal of smoothing.
- Cached held-out quadratic forms so every candidate and fit uses exactly the
  same discrepancy, normalization, evaluation reconstructions and dyad axis.
- Clean-field, known-coefficient and same-window quadrature diagnostics.
- A separate prototype enforcing complete degree-2q quadrature moments on the
  coarse comparison grid, with infeasibility exposed rather than hidden.

What the failures mean:
1. Old short supports amplify derivative noise and attenuate coefficients.
   Broader, operator-aware weak supports solve much of this on KS and KdV.
2. The new coarse-grid windows can be inaccurate even on clean data, notably
   for NS. Refining the same physical integrals improves accuracy, so numerical
   integration needs its own control. The stricter polynomial-moment guard
   helps partly but is infeasible for the full wave panel on its training grid.
3. The current noisy evaluation bank can badly mis-score the exact law. Forced
   KdV's exact-coefficient cross-products are approximately +1997,+1460,-1338
   across seeds, against a clean energy near 3.7e-7. Fitting alone cannot cure
   this discrepancy instability. See failure_analysis.txt for the controls.

Decision: retain this as an experimental fitting implementation, with a clear
KS improvement, rather than replace the production fitter globally. The next
solver-free revision should combine quadrature-controlled weak fitting with
evaluation moments selected for operator uncertainty. Keep the old estimator
as the benchmark until the regressions are resolved across all 15.

Validation and limitations:
- All 45 system-seed cases completed, 15 default saved systems, 5% noise,
  3 seeds, 3 reused training/evaluation rotations; 60 equation-seed cases.
- Bootstrap budgets and evaluation fields match the previous latest baseline:
  128 draws for ac, kdv_cossin, pde_compound, pde_divide, ns; 32 for the rest.
  Half/full comparison changes two reconstructed-CLSM cases (three bandwidth
  entries); no raw-CLSM retained/not-retained outcome changes. This is only
  computational sensitivity, not a complete uncertainty interval.
- Frozen scores reproduce the saved baseline with maximum scaled difference
  6.73e-10. Independent finite-distribution enumeration verifies corrected
  moment expectations to 1.78e-15; scaled linear regression error is 4.52e-11.
- The strict quadrature follow-up completed seed 0 for ns, kdv_cossin, ks and
  ac. Wave seed 0 was infeasible. It is a diagnostic follow-up, not an all-15
  result, and has not been used to overwrite the main comparison.
- No candidate equation integration, PINN, numerical PDE solution, new search,
  or clean-data-based fitting/selection occurred. Production files were not
  changed. Parallel independent diagnostics ran after the user's permission;
  numerical processes used one BLAS thread and below-normal priority.
