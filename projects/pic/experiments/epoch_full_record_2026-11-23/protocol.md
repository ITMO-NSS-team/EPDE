# Full-sample, epoch-budget EPDE discovery

Run the 15 core systems and the separate harmonic-oscillator control with paired search seeds 923701–923703 at 0% and 5% added Gaussian noise. Scale noise separately by each field’s standard deviation. Pass every stored measurement to discovery. Lorenz uses all 100,000 original time samples. Navier–Stokes uses all 200 times and its full 50 × 100 spatial grid. Check the full-field hashes at assessment.

Run the existing plain-mode, solver-free NSGA-II weak-form pipeline for 50 complete epochs on scalar systems and 150 on coupled systems. Each run uses automatic population sizing and disabled patience. Record the realized population size, epoch count and fitness calls. Increasing the number of fits cannot stop a run. The configured library includes field and derivative factors, coordinates and data-proposed trigonometric frequencies. Forced KdV also has its catalog source token. Weak windows are selected from the observations before equation discovery. WAPE and coefficient instability across dyadic slabs are the two evolutionary objectives for each equation.

Retain the preceding experiment’s frequency refinement. After 2,400 fit calls it visits up to 12 distinct eligible equations once. Each trial frequency refits the linear coefficients on the same weak rows. Improved variants enter the experimental archive. Evolution continues from the native parents. This auxiliary work is recorded separately.

The primary endpoint is a complete system on the native first Pareto front at the final epoch. A candidate qualifies through a catalog match or a verified equivalent identity. Count each successful run once. For Lorenz, the historical full-system classifier requires the identities in one candidate to span all three reference laws. The oscillator control also accepts its verified phase and energy identities. Preserve literal and catalog matches as diagnostics.

Apply the same recovery rule to the ordinary-discrepancy front and the two-slab and all-scale cross-validated discrepancy fronts reconstructed on the actual candidate systems from the whole search. The previously used archival WAPE ceiling of one applies to those three reconstructed fronts. CV freezes target, support and frequencies, refits the linear coefficients outside each native weak-row slab, then predicts the omitted slab. Average WAPE across folds, scales and axes. Report front sizes and recovery by noise condition. The seed-matched prior 3,000-fit results used shorter inputs on Lorenz and Navier–Stokes.

For the subsequent early-stopping question, record the set of native first-front structures after every epoch and count consecutive unchanged transitions, using EPDE’s own structure labels. Compare the first trigger for explicit patience 3, 5 and 10 against the full-epoch endpoint on the same run. Report complete-system recovery at the trigger, final recovery and epochs saved. Each search still executes its full budget.
